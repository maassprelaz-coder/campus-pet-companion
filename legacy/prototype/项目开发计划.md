# 校园陪伴式养成电子宠物 - 项目开发计划

基于《心理竞赛.docx》提供的完整PRD文档，为了确保项目的高效交付与结构清晰，将开发过程划分为三个核心阶段。

## 核心架构与技术选型（Web版先行）
- **前端框架**：React + Vite + TypeScript（快速搭建现代Web页面）。
- **状态管理与样式**：Zustand (轻量级状态管理) + Tailwind CSS (快速响应式布局)。
- **AI 大模型接入**：
  - 核心：使用大语言模型（LLM）驱动宠物的**对话回复**与**行为决策**。
  - 机制：通过 Prompt 工程，让大模型在回复聊天内容的同时，输出宠物的“动作指令”（如 `[打滚]`, `[睡觉]`, `[开心]` 等）。
  - 表现形式：由于目前缺乏美术动画资源，所有动作暂时使用**文本或Emoji代替**显示在界面上（例如：“宠物当前状态：(づ｡◕‿‿◕｡)づ [正在打滚]”）。
- **本地存储**：使用浏览器 `localStorage` 保存用户的翻译币数量、宠物名字和历史日记等数据。

---

## 阶段一：V1.0 核心玩法 (MVP阶段)
**目标**：建立宠物生命感，跑通“行为 -> 翻译币 -> 解读”的核心经济循环。

1. **基础框架与启动流程**
   - 搭建项目基础路由与状态管理。
   - 实现启动界面：宠物滑动选择（糯米团子、奶盖等）。
   - 实现命名功能及确认领养交互。
2. **主世界大地图（基础版）**
   - 绘制并实现校园地图基础布局。
   - 实现 **小屋** 场景：宠物吃饭、睡觉、玩耍动画。
   - 实现 **图书馆** 场景：宠物安静看书动画。
   - 宠物大地图基础交互：点击触发转圈、打滚、眨眼等动作。
3. **核心数值与任务系统**
   - 实现基础货币系统（翻译币的增减逻辑）。
   - 实现 **签到系统**（圈1功能）：每日签到获取翻译币。
4. **想法泡泡系统**
   - 开发宠物头顶随机弹出的“乱码”想法泡泡。
   - 实现消耗翻译币解译暖心短句的功能。

---

## 阶段二：V2.0 场景扩展与基础功能
**目标**：丰富陪伴场景，增加用户主动投入的功能（日记、专注），提升留存。

1. **地图场景补全**
   - **教学楼**：宠物看网课、戴耳机动画。
   - **食堂**：宠物美食幻想动画。
   - **操场**：宠物跟随行走动画。
2. **右侧核心功能菜单开发**
   - **心情日记**（圈2功能）：实现文字日记记录及本地保存，完成后发放翻译币。
   - **合照功能**（圈2功能）：调用相机，实现与宠物AR合照（或简单的图片叠加合照），并记录历史。
   - **专注计时器**（与图书馆联动）：实现25分钟番茄钟，倒计时防作弊机制，完成后发放奖励。
3. **互动游戏模块**
   - **互动小游戏**（圈3功能）：实现如“接住零食”、“抚摸计数”等简单滑动/点击小游戏。

---

## 阶段三：V3.0 深度互动与拓展
**目标**：建立深度情感羁绊，打破APP边界（小组件）。

1. **宠物特写大界面**
   - 开发全屏无背景（纯色）的特写界面。
   - 实现注视反馈（跟随手指滑动转头）。
   - 实现触摸身体部位触发动作表演。
2. **自由交流功能**
   - 集成语音/文本输入功能。
   - 实现消耗翻译币进行对话互动的逻辑（预留AI大模型接口或基于关键词的回复库）。
3. **桌面小组件 (Widgets)**
   - **iOS/Android 原生开发**：开发桌面小组件，同步展示宠物的当前状态（睡觉、看书等）。
   - 实现点击小组件直接唤起APP进入主世界。
4. **限定活动框架**
   - 搭建节日活动弹窗与特殊道具发放逻辑（圈4功能，如端午节云粽子）。
