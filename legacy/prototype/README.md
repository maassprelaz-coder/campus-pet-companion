# 🏫 校园陪伴式养成电子宠物 (Web & 桌面双端版)

这是一款充满“生命感”的陪伴型电子宠物应用。它不仅能在绝美的水彩手绘校园里漫游，还能通过**真实的 GPS 坐标**在现实世界里跟着你走，通过 **AI 视觉 (MediaPipe)** 乖乖坐在你的手心里，还能用 **DeepSeek 大模型** 读懂你的日记并给予暖心回应。更可以通过 **Electron** 化身为屏幕上自由拖拽的无边框桌宠！

---

## 🌟 核心功能一览

### 1. 🐶 多角色与专属动画系统
*   **四大萌宠可选**：开局可选择领养「小狗(活泼)」、「小龟(慢条)」、「小羊(温柔)」、「猫咪(傲娇)」。
*   **全套真实动图接入**：每个宠物都配备了专属的高清 GIF 动作库（待机、开心、睡觉、吃饭、打滚、思考、伤心流泪）。
*   **待机摸鱼机制**：挂机状态下，宠物会按 30% 的概率随机做出思考、打滚或蹦跶的小动作，拒绝死板发呆。

### 2. 🗺️ 沉浸式校园漫游与 GPS 寻路
*   **手绘地图无缝穿梭**：基于 3840×1760 超大手绘地图，支持鼠标拖拽漫游。内置 8 个精准地标（宿舍、图书馆、教学楼、两座食堂、两个操场、大草原）。
*   **打破次元壁的 GPS 跟随**：通过手机/电脑的真实定位，当您在现实中走到校园的某个建筑（距离 < 150米），地图会自动跟随到该点，宠物也会开心地跑来找您！
*   **场景专属行为**：去图书馆会自动安静睡觉/看书；去食堂会自动流口水干饭；去操场会开心打滚。

### 3. 🤖 大模型深度交流与情绪共鸣
*   **性格化对话**：接入 DeepSeek 大模型。对话时，宠物会基于其特有的性格（如傲娇或黏人）来回答。
*   **翻译币经济闭环**：宠物最初只会发出动物叫声（如“喵呜”）。需要消耗每日任务赚取的“翻译币”，才能解译它真正的中文内心想法。
*   **双屏日记本**：左边写日记，右边宠物实时陪伴。大模型会**实时分析你输入文字的情绪**，宠物会根据你的心情瞬间表现出开心或落泪的同理心反应，并在保存后自动生成专属的“🐾 宠物留言”。

### 4. 🖐️ MediaPipe AI 视觉互动与拍立得相册
*   **跳上手心**：打开摄像头，平摊手掌，宠物会自动识别并跳到你的掌心上坐着。
*   **摸头享受**：用另一只手的手指触碰屏幕里的宠物，它会立刻闭上眼睛露出享受的表情。
*   **拍立得合照系统**：提供 8 款（4竖4横）精美拍立得相框。AI 会将真实的摄像头画面智能裁剪，与你手心里的宠物完美合成，并挂到专属的“照片墙”上。

### 5. 🖥️ 无边框桌面悬浮桌宠模式
*   基于 Electron 开发，一键切换进入“桌宠模式”。
*   整个大地图和游戏 UI 瞬间隐形，只剩下一只小动物**无边框地悬浮在你的电脑桌面上**。
*   支持任意拖拽位置，支持鼠标悬浮菜单进行“摸摸”互动和实时计数，摸满 10 次还会奖励翻译币。

### 6. 🎒 番茄钟与任务家具系统
*   **图书馆番茄钟**：真实的 25 分钟专注倒计时，期间宠物会乖乖睡觉陪你。
*   **每日红点任务**：完成签到、日记、合照、番茄钟后，右侧菜单会亮起小红点，提醒领取翻译币。
*   **宿舍装扮**：可以用赚来的币在商店购买豪华软床、毛绒地毯等，装饰宠物的专属宿舍。

## 🚀 如何运行本项目？

项目采用纯原生前端技术栈 (HTML/CSS/JS) 编写核心逻辑，搭配 Electron 实现桌面端打包，**零配置，轻量极速**。

### 方式一：作为网页端运行（体验基础功能与 AR 合照）
由于浏览器安全策略，**千万不要直接双击打开 `index.html`**（这会导致摄像头调用失败和相片保存崩溃）。
1. 请使用 VS Code 打开此文件夹。
2. 安装 `Live Server` 插件。
3. 右键点击 `index.html`，选择 **Open with Live Server**。

### 方式二：作为桌面客户端运行（体验无边框悬浮桌宠，推荐！✅）
要体验终极的透明悬浮桌宠模式，请确保您的电脑安装了 [Node.js](https://nodejs.org/)。
1. 在当前项目文件夹中，右键打开终端 (Terminal / PowerShell)。
2. 运行环境安装（只需执行一次）：
   ```bash
   npm install
   ```
3. 启动桌面客户端：
   ```bash
   npm start
   ```
   启动后，登录游戏，点击右侧的 **[🖥️ 桌宠模式]** 按钮，见证魔法吧！
