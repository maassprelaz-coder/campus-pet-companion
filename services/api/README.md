# 连接与任务服务工作入口

主责A。**把真实GeniOS、网页和任务反馈接通，只补平台缺少且主线需要的能力。** 详见[A任务卡](../../docs/assignments/A_integration.md)。当前尚无真实服务实现。

先确认平台能力，再决定是否需要自建服务。需要时采用单一服务和简单持久化即可，例如团队熟悉的Node.js与SQLite；是否采用、部署能否持久保存由A实际核实。框架不是比赛要求，不为项目额外建设复杂账号、微服务或后台。

结合旧专注/任务规则和真实平台完善[接口草案](../../contracts/README.md)。正式服务由可信会话确定主体，检查每次读写的归属；模型只推荐已实现模板。积分可简化或不采用，若采用则固定规则、事务结算与唯一完成记录，不能相信客户端或模型传入的奖励金额。

任务完成校验状态和实际时间，重试不重复生效；同幂等键不同负载冲突。AI失败不撤销已经确认的完成结果，允许重试文案。mock只供独立联调，不是生产鉴权、存储或平台适配实现。

A交真实文档与脱敏调用后再设置endpoint、鉴权和响应转换，不能猜校园Coze兼容性。凭据仅在受控服务配置中；日志保留必要匿名信息。发布前验证持久化、HTTPS、错误恢复和不同会话隔离。

当前契约remember只接受false，记忆能力未实现。未来若按评分/需求值得加入，由A确认授权、隔离、删除及平台限制，再同步接口、样例、页面和验收，不能单改提示词开启。
