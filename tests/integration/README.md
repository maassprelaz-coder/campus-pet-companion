# 真实系统必须验证

由 A 统筹，B/C 分别提供模块证据：

1. 新会话进入选定校园场景→真实GeniOS建议→用户接受选定行动→合法完成→宠物反馈。专注是候选，不强制固定为25分钟或必须采用积分；采用积分时验证一次结算。
2. 普通倾听和用户拒绝建议不会偷偷建任务；资料不足时不编造校园事实。
3. 不同会话不能读/改彼此任务；伪造 user_id 无效。当前无长期记忆，如扩展再增加相应隔离、同意与删除验收。
4. 重复完成事件只结算一次；未开始、提前完成及同 key 不同负载被拒绝。
5. 关闭主动建议、拒绝可选权限仍可使用；首版 remember 固定 false，不保存或传递跨会话历史。
6. GeniOS 超时/无效结构/客户端断网不破坏已完成任务，可按实际规则恢复。
7. 第二台设备以评审可用身份打开真实链接，验证同一功能版本。

记录预期/实际/通过与否/日期/版本/证据。情境对照、知识来源、主动建议抑制和选定亮点由对应模块负责人补测；E组织真实试用并记录实际等待时长。根目录 npm run check 只验证开发用模拟服务，不代替以上真实系统测试。
