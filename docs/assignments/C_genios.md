# 张祺昌的任务

**张祺昌，你负责在南开 GeniOS 上把真正能用的陪伴智能体搭出来，让它能根据用户说的话和所在场景给出合适建议，并发布一个评审能打开的链接。**

这部分负责“宠物理解什么、怎么回应、为什么给这个建议”。网页的外观交给 Seventy，任务记录和整体联通交给仓库负责人，你先把平台本身跑通。

## 具体要做什么

1. 第一件事是确认账号能登录、智能体能发布、发布链接能被另一个获准账号打开。再确认平台是否支持给我们的网页调用，把实际文档和脱敏的成功例子交给负责人；不能调用也要当天说明。
2. 先实现三类情况：想专心学习、想休息放松、只想聊聊。回复要结合用户表达和场景，建议允许拒绝，信息不足就追问，不是固定的一句话回答所有问题。
3. 设置宠物的回复风格，并把资料同学整理的可靠校园信息放入知识库。资料中没有的开放时间、电话或地点不要编造。
4. 用工作流把输入判断、必要检索和回复生成串起来，按约定返回回复、宠物动作和可选任务。积分和任务编号由业务服务处理。
5. 记录实际运行效果，提供提示词、工作流说明、知识库来源、配置截图或真实导出文件，以及发布后的访问说明。

## 怎样独立开始

先填 [平台确认单](../../agent/PLATFORM_CHECK.md)，再读 `agent/` 里的提示词和工作流草案。用 `contracts/fixtures/` 的样例直接在平台调试，不用等网页完成。草案不是已运行的配置，需要你实际验证后修改。

主要维护 `agent/`，平台上的配置也由你统一编辑并保存版本。密钥、校园密码和带凭据的截图不进仓库；不把商业 Coze 的接口直接当成学校平台接口。

## 最后交什么

真实智能体链接、访问条件、一次成功调用的脱敏输入输出、三类情境的实际测试记录，以及比赛要求的平台配置材料。若某项能力平台不支持，清楚写出限制和已实现部分。
