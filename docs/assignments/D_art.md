# 美术资源同学的任务

**你负责准备网页里真正会用到的宠物、宿舍背景和按钮图标，把文件整理成 Seventy 拿到就能放进页面的资源包。**

先把一只宠物和一个宿舍场景做齐。可以整理已有素材，也可以补充自制或允许使用的资源；不用一开始就搜大量宠物和装饰。

## 具体要做什么

1. 先找 Seventy 确认页面需要哪些图片、尺寸和格式。优先准备宠物待机、开心、思考等实际用到的动作，缺少的动作直接标出来。
2. 准备一张宿舍背景和少量按钮图标。尽量统一画风，确认透明背景、动画能否播放，以及文件大小是否适合网页。
3. 给文件起清楚的名字，按宠物、背景、图标分开整理，并做一张预览图或简短说明。
4. 记录每项素材的作者或来源、链接及使用许可。来历不清楚的现有音乐和图片先列为待核实，不直接算可发布资源。

## 怎么交接

资料整理在 `content/assets/pet-ui/`，来源填同目录的 `source-register.csv`。不会用 Git 也没关系，可以按同样结构交资源包，由负责人入库；你仍负责确认文件与来源清单完整。

## 最后交什么

一份能直接使用的最小资源包、预览和来源表。Seventy 实际放进网页后确认没有尺寸、透明背景或动画问题，就算完成第一轮；后续再补缺项。

## 时间安排

10 月 14 日先确定清单并交已有可用素材，15 日前补齐第一版。16 日配合调整，17 日固定用于最终截图和视频的资源，不临时大换画风。
