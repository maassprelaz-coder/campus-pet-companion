# 美术同学负责：把实际用到的画面和资源做好

**你要让宠物和校园场景看起来统一、清楚、有吸引力，并把资源整理到Seventy拿到就能接进网页。先看已有素材哪里好、哪里缺，再决定保留、修改或新做。**

你负责视觉质量和可用资源，不只是大量搜图。已有28个动作GIF、4张相框、地图、背景和音频，具体见[已有项目评估](../EXISTING_PROJECT.md)；这能省时间，但不要求强制沿用。你的成果主要支撑场景体验、创新表现和文档展示。

## 具体要做什么

1. 先盘点旧素材：能否打开、动画是否正常、画风和清晰度、体积、来源许可。把值得保留、需要替换和缺少的部分列出来；不覆盖历史原件。
2. 向B确认实际采用的页面、宠物动作、图片尺寸和显示比例。B尚未完成时先做素材预览和来源表，不必等正式页面；不要先制作一整套未确认会用的界面。
3. 交首批可用资源，覆盖选定宠物的基础表现、使用中的场景和必要图标。先保证能演示一套完整体验；其余宠物已有且质量好可保留，不必为了“最小版本”人为删掉。
4. 对比旧画面提出一项最值得改进的视觉点，例如建议卡更清楚、动作与反馈一致、合拍相框更有校园辨识度。按B确认的实现成本排期，避免只能看设计图却接不进去。
5. 每项记录路径、用途、尺寸、格式、透明/动画说明、来源/作者、许可和替换关系。来源不明单列；需要替换时可自制或选许可明确资源。校园地标事实/照片由E核对，你与B负责视觉使用。
6. 16日在实际网页复看文字、遮挡、缩放和动画，17日固定用于截图视频的版本。不能只交孤立图片而不检查接入效果。

## 怎样算完成

B能依说明直接加载资源；没有明显拉伸、遮挡、透明底错误或动画失败；主线所需动作有对应画面或明确回退；正式展示素材来源清楚。E能用最终资源整理视频与介绍，不必再猜哪个文件是最新版。

如果主线稳定，你还可以协助E做封面、截图标注或合拍效果展示；优先选择对评审看懂作品有帮助的改进。18日协助检查材料，不临时大改整套风格。
