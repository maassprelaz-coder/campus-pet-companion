# 仓库负责人任务

**你负责把宠物网页和 GeniOS 智能体接起来，让用户收到建议后能够接受任务、完成任务并得到反馈，最后合并成一个能演示的参赛版本。**

你主要处理页面背后的请求和记录，以及大家成果的合并。先确认平台已有能力能做哪些，缺哪一小部分再补，不开发独立 App、复杂账号体系或长期记忆系统。

## 具体要做什么

1. 先同 Seventy、张祺昌确认 [接口样例](../../contracts/README.md)。它约定“页面传什么、智能体返回什么、任务怎样开始和完成”，确认后第一轮不随意改字段。
2. 张祺昌验证平台期间，用已有模拟回复开发必要的任务记录。用户接受建议后才建立任务，完成后按固定规则结算，重复点击不能重复奖励。
3. 拿到张祺昌提供的真实调用资料后，把页面请求转给 GeniOS，并将结果交回页面。平台密钥放在服务端，不能写进网页。
4. 处理刷新恢复、调用失败和重复请求。不同使用者的任务记录不能互相读取。先保留完成参赛流程所需的最少数据。
5. 检查并合并各人的改动，安排真实链接和第二台设备体验。平台自身能完成的部分直接使用；不能外部调用时，当天同张祺昌确定实际可交付形态。

## 怎样独立开始

主改 `services/api/`、`tests/integration/`、`docs/release/`。先读 [业务服务说明](../../services/api/README.md)，用 `contracts/fixtures/` 开发，不等别人完成。Seventy 管页面，张祺昌管平台配置，不同时改他们的文件。

## 交给大家什么

可调用的服务地址或平台联通方法、启动说明、必要配置项名称、实际测试结果，以及最终整合版本。合并时由每个人修复自己模块的问题；截图和平台配置说明分别由 Seventy、张祺昌提供。
