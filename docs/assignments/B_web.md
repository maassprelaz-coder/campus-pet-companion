2. 做出清楚的校园陪伴入口。现有领养、地图和宿舍只保留对体验有帮助的部分，用户能看懂当前场景、怎么说话、建议在哪里。必要回复直接可读，旧版“翻译扣币”不能挡住基本交流；用户文本和模型回复按文本显示。
3. 接上回复、宠物动作、可选建议和资料来源。用户可以拒绝或关闭主动建议；场景进入等事件可触发适度应用内提醒，但不要反复催促。动作统一映射到约定枚举，缺少动作有可用回退画面。
4. 接受建议后显示真实任务状态。旧专注计时和任务中心可以改造：显示服务确认的开始时间和完成结果，刷新能恢复，页面不自己决定积分。拒绝建议不发接受请求；奖励规则与旧任务映射由A一起确定。
5. 处理等待、无建议、网络失败、平台失败和资料不足。连接地址可配置，切到真实服务后完整验证；定位、摄像头拒绝时基础流程仍可用，不自动上传输入草稿。
6. 核心流程稳定后，评估手势合拍、宠物动作或视觉改进能否形成清晰亮点。已有合拍代码若容易恢复且实机稳定，可以加入；若成本高就换更有效的改进。无需新增手机App或桌面安装包。
