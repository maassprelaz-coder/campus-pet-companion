# Seventy 的任务

**Seventy，你负责把能看到宠物、聊天、选择校园场景和接受任务的网页做出来，让别人打开链接就知道怎么用。**

先做浏览器里能操作的页面，不做手机 App 或桌面安装包。已有原型可以提供宠物动画和界面参考，不需要重新设计整个项目。你的 GitHub 账号记录为 `zhaozishi123`。

## 具体要做什么

1. 从旧原型里挑一只宠物、宿舍页面和必要素材，整理到 `apps/web/`。先保证页面可用，其他宠物、装饰和手势合拍放后面。
2. 做好聊天输入、手动场景选择和回复显示。智能体给出行动建议时，页面显示“接受”和“暂时不用”等明确选择。
3. 用户接受后，显示任务、倒计时和完成反馈；刷新后能恢复服务返回的任务状态。页面只显示结果，不自行决定加多少积分。
4. 加上等待回复、网络失败、没有建议等状态。主动建议可以关闭；基础操作不强制要求定位或摄像头。
5. 接到真实服务地址后更换连接配置，验证同一套页面可正常使用。最后提供真实界面截图和一段操作录屏。

## 怎样独立开始

先读 [客户端说明](../../apps/web/README.md)。仓库根目录运行 `npm run mock`，用它提供的模拟回复做页面，不必等后端或智能体完成。[接口约定](../../contracts/README.md)和样例已经准备好；模拟结果不能作为参赛实际效果。

主要修改 `apps/web/`，旧 `legacy/prototype/` 只作迁移参考。美术同学将资源交到 `content/assets/pet-ui/`，资源没到齐时可先用简单占位图搭页面。现有旧模型请求、账号和积分逻辑不要原样搬过去。

## 最后交什么

可运行的网页、启动说明、服务地址配置方法、截图和录屏。验收时让另一个人完成“进入页面→选场景或聊天→接受/拒绝建议→看到任务与反馈”，并能说明出错时页面如何提示。
