# 两人交接明细

2026-10-15起只使用A（你）和B（Seventy）。交接标准是对方能继续工作，不是只说“写好了”。各自写docs/handoffs/A或B，A汇总总进度。

| 交接 | 时间 | 必须交什么 | 对方如何验收/等待时做什么 |
| --- | --- | --- | --- |
| A→B 平台路线 | 15日开工首轮 | 登录/调用/发布/访问的实际结果；采用外接网页或平台内方案；限制与下一步 | B据此决定入口；未核实时先盘旧页面和用mock |
| B→A 页面与赛务 | 15日开工首轮 | 可用/失败模块、选择理由、字段与动作缺口；最新提交字段/时间/模板或未核项 | A能定核心流程；未取得的通知不当已知 |
| A→B 联调包 | 15日争取，16日上午检查 | 地址、启动配置名（无密钥）、会话方式、接口版本、真实请求响应、动作/任务白名单、错误样例 | B照例完成一次真实调用；未到时用合成fixtures，保留mock标识 |
| B→A 网页包 | 同上 | 分支/提交、启动方法、服务配置、采用素材及来源、正常/拒绝/失败/刷新步骤 | A能在另一设备启动并走通；B自行修页面问题 |
| B→A 试用问题 | 16日真实版本后及时 | 匿名编号、日期/版本、尝试/完成、耗时定义、设备、错误步骤与反馈 | A复现技术问题并返回修复版本；无真实试用就注明缺失 |
| A→B 技术材料 | 17日，给B留整合时间 | 实际提示词、知识来源、工作流截图/真实导出、模型配置实证、URL/访问条件、技术说明与测试 | B可把介绍里的技术表述对应证据，不自己猜 |
| B→A 提交包 | 17日彩排前 | 介绍PDF、MP4、截图、支撑材料、真实成效统计、未决项及文件大小清单 | A逐项审核，同一版本，签字件仅入授权提交入口 |
| A→B 提交结果 | 18日提前提交后 | 实际回执、提交版本、可访问性结果 | B核对，未提交不标完成 |

接口v0.1仍为内部草案，不是学校API。A/B对照旧任务、中文动作和真实平台确认采用字段；只开放实际可执行的任务。改字段时写原因、旧/新例子、受影响页面与切换时间，A更新公共契约和样例，B同步页面。

平台无法外部调用时，A当天核实平台内能否完成情境、选择与反馈，B调整到真正能接上的形态；不能把两套独立演示称为集成。无法满足硬要求则标阻塞、优先解决权限，不以mock替代GeniOS。

每次记录：负责人/任务ID、提交或平台版本、实际完成与未完成、启动步骤、实测环境与结果（mock/live）、文件/证据、交给谁、需要对方什么及最晚时间、下一步。凭据和私密原文不入库。
