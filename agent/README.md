交付实际提示词、实际模型/参数配置、知识库来源版本、逐节点工作流、配置截图与真实导出（平台支持时）、测试结果、URL和访问条件。导出放exports，不用手写schema冒充。平台编辑由C统一管理版本，凭据不入库。
