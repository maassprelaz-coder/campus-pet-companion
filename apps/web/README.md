# 网页工作入口

主责Seventy。**把用户实际操作的宠物网页做好，接上真实智能体的建议、选择和行动反馈。** 详细步骤、验收、日期与交接见[B任务卡](../../docs/assignments/B_web.md)。此目录目前没有正式参赛网页实现。

先检查旧页面与素材的实际效果，再决定复制改造还是局部新做。原型是原生HTML/CSS/JS加Electron壳；不预先要求换框架，也不强制沿用。旧专注、任务和合拍并非全要重建，记录保留/改造/替换依据。

先使用根目录 `npm run mock` 和 [v0.1草案](../../contracts/README.md)独立联调，本地页面用5173端口或同A协调模拟工具配置。服务地址可配置，mock明显标记。只实现A/C确认的可执行任务；不要因fixtures包含两个模板就承诺两种任务都完成。

建议小步交付：先交现状与缺口表；再交能操作的主流程并接真实服务；最后修复问题、验证选定亮点、交截图录屏。D交资源后由B接入，C不直接改页面。用纯文本显示输入输出，动作只取白名单；拒绝授权仍可使用基本功能，不自动发送草稿，不由页面决定奖励。

当前记忆接口关闭；如后续有高收益改进，按评分计划和公共接口流程确认后扩展。手势合拍、视觉等值得做的功能允许排入，以稳定、真实和可按时展示为准。不新增手机App或桌面打包。
