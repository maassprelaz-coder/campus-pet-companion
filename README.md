## 本地独立联调

使用Node.js 22或更新版本；现有工具不需要第三方依赖：

```sh
npm run check
npm run mock
```

mock只监听 `127.0.0.1:8787`，允许本地5173端口页面；响应标有模拟状态，不连接模型，不能作为参赛实际效果。[接口v0.1](contracts/README.md)是内部草案，需要结合旧任务和真实平台确认。两人可用相同样例独立工作。

`legacy/prototype/` 是已清空发现的模型凭据的只读历史副本。仍有旧登录、直连模型、桌面权限等待评估实现；有益内容复制到各自目录后改造，不原样当公网参赛版。仓库保持私有；学校账号、密钥、私密日记、签字材料不入库，历史素材许可待逐项核实。
