# 校宠伴行

面向南开大学2026年“华为杯”AI应用创新大赛软件赛道的校园宠物陪伴项目。**目标是依据评分交付可体验、有实际效果的智能体；旧项目有利的部分可以复用，也可以改进或替换。** 截止日为10月18日，具体时刻待赛务核对。

当前仓库已有脱敏历史原型、分工计划、接口草案和本地模拟工具。旧项目有宠物、地图、宿舍、聊天、专注、任务/家具和合拍代码，运行效果尚待验证；真实GeniOS接入、可靠任务流程、评审URL、试用和参赛材料尚未完成。此轮更新主要是计划，不代表产品已开发或部署。

## 按什么顺序做

评分为场景价值20、技术规范25、创新扩展20、实施成效20、文档展示15，依据见[比赛通知与要求](docs/REQUIREMENTS.md)。先查清平台调用/发布和旧功能现状，15日争取真实完整流程，16日开始试用，17日修复并整理材料，18日提前提交。

核心体验是“情境→GeniOS决策与建议→用户选择→实际行动→宠物反馈”，校园知识有来源、主动服务可关闭。先选一条有价值的行动做可靠，旧专注流程是候选，不强制实现样例里的每种任务。手势合拍、视觉、成长反馈等若明显改善评分且能验证，可以加入，详见[评分取舍](docs/SCORE_PLAN.md)与[范围验收](docs/SCOPE.md)。不另做手机App、Electron打包或商店发布；平台自带能力足够时减少自建部分。

## 本地独立联调

使用Node.js 22或更新版本；现有工具不需要第三方依赖：

```sh
npm run check
npm run mock
```

mock只监听 `127.0.0.1:8787`，允许本地5173端口页面；响应标有模拟状态，不连接模型，不能作为参赛实际效果。[接口v0.1](contracts/README.md)是内部草案，需要结合旧任务和真实平台确认。三人可用相同样例独立工作。

`legacy/prototype/` 是已清空发现的模型凭据的只读历史副本。仍有旧登录、直连模型、桌面权限等待评估实现；有益内容复制到各自目录后改造，不原样当公网参赛版。仓库保持私有；学校账号、密钥、私密日记、签字材料不入库，历史素材许可待逐项核实。
