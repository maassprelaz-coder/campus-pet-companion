# 真实试用记录说明

E负责组织，A/B/C提供真实可用版本并处理各自模块问题。当前CSV只有表头，没有试用数据。16日开始试用是内部计划，不是已经完成的事实。

使用 `record-template.csv` 的列另存匿名记录，写日期、代码/平台版本、统一任务、是否完成与失败步骤。`elapsed_seconds` 专用于本次规定流程的总耗时，不和模型等待时间混用。需要测响应时另建等待记录，列匿名编号、版本、请求序号、发送时间、首个可用答复时间、等待秒数、成功/失败/重试及测量方法；只收集必要匿名数据，不附原始私密聊天。

流程完成率报告完成者/尝试者的实际人数，再给百分比；中途退出、请求失败和缺失记录单列，不能从分母消失。等待统计写实际请求数和测量口径；样本很小时优先列原始范围和观察，不宣传未经证实的改善幅度。

mock、开发自测与非开发者真实体验分别标记，只有后者计入所述真实用户试点。先建议3–5位自愿同学，人数不是比赛门槛，也不能补造。17日将实际记录、问题修复版本和仍存在的限制交A与提交材料目录。
